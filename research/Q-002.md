## The question

What mechanisms let a web application create commits, files, comments or reviews in a person's private GitHub repositories on that person's behalf?

Cover at least: a GitHub App (installation token and user-to-server token), OAuth app user tokens, and fine-grained personal access tokens. For each: how the resulting commit, comment or review is attributed (which identity GitHub shows as author, committer and actor, and whether a workflow can tell it apart from the person acting directly on github.com); the narrowest permissions possible; token lifetime and refresh; where the credential must be stored; what an attacker who obtains it could do; and the person's setup and upkeep.

The decision it serves: how Service Desk records the owner's answers and rulings, and whether such an answer can count as the owner's own GitHub action (docs/PROJECT.md §7 U2 and §8).

Depth: 3, a graded memo. Topics: github, authentication, attribution, security.
