A clearer hierarchy, and every icon folds

Your comment on v19, on S-011 frozen and what it needs:

"I’m not sure how, but this hierarchy needs to be slightly more defined. And every icon should be able to collapse/exoand"

The folding works the same in all three. An icon with a ring has something under it. Tap an event's icon to fold what it needs, what it unlocks and why; folded, one line says what is there, and tapping it opens again. Tap a requirement's icon to open what that requirement needs in turn, one level deeper; tapping its words still takes you to it. The three options differ only in how the levels are set apart.

Each phone opens on the timeline project with S-011's planned events at the top. Tap the ringed icons. Try Spec revised, round 4's icon inside Plan review, round 4.
