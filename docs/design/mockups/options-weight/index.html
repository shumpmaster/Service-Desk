Each event as heavy as it is

Your comment on v21, on S-011's events:

"This entire flow here is solid, but in its current visual format every single event has the same weight and means nothing unique, can we change that"

Today a routine commit, a failed review and a stop that waits on you all get the same row. Below: v23 as it is, then three live ways to weigh them. The order and the tree stay, and so do the Needs and Why tags. Each event gets a weight from what it is:

Turning points: a stop, a decision, a gate, a merge to main, or anything waiting on you. Checks: a review or a check, passed or failed. Routine: a commit (a draft or a revision). If that sorting is wrong, say so; it's a rule, not a choice per event.

Each phone opens on the timeline at S-011. Scroll inside it. No new colours: only the soft status ones.
