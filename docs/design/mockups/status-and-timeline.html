Worth knowing

  • The mockup shows a few entries from each phase; the real feed lists every pull request.
  • Each colour is backed by words, so nothing depends on colour alone: the phase name is pinned above its stretch of the line, and each bullet keeps its label.
  • Titles are each pull request's plain-English opening line. The oldest pull requests' opening lines were written in technical terms, so the desk shows them as recorded.
  • The trial-view pull requests (#72 to #77) aren't filed against MD2 in the plan yet, so the desk can't tie them to a milestone. Filing them is a small plan fix.
  • Text boxes will use 16 px text, so the phone stops zooming in when you tap one.
