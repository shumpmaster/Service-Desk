# Ruling needed: How should a question's card fill in your answer?

Milestone: MD2
Asked in session: session_012RJPVKAoLga2RkqLYRDcBY

WHY: On the board, a question's card has one link to the answer file, filled in as far as GitHub allows. The question is how much is filled in for you. Left unruled, the card fills in everything but your choice of letter.
OPTIONS:
  A. One button, you type the letter — "Answer" opens the answer file with everything filled in except the letter after "Ruling:".
  B. One button, recommended letter filled in — "Answer" opens it with the recommended letter already there; you change it if you disagree.
  C. One button per option — "Answer A", "Answer B" and so on, each opening a fully filled-in file; one tap and commit.
RECOMMENDATION: C — still one tap to a ready file, and the recommendation stays labelled rather than chosen for you.
