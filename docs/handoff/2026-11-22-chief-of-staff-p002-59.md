## Lessons for the model
- **The review check's skip-marker flag matches `process.exit(`** (it reads `xit(`). Any test-side file that exits the process with `process.exit` will need the owner's verdict. Raise it in the operating model. Until then, a builder writing a test-side script can use `process.exitCode = n` instead. That has to be said in the brief, because the adapter cannot change once a record holds its hash.
- **A spec's description of today's behaviour can be wrong even after a code reading.** The reading (:290) described the link's sheet only before the read settles. Before a baseline is made, probe each route the spec describes for today, as this dispatch did. The probe is where this showed.
- **Hash files read at load time, not only imports.** The locked check's import walk misses JSON a helper reads. Name them in the record script.
