## Done
- **Motion, then the plan.** v2 to v5 settled how the timeline behaves:
  - the desk's trunk branches into a project;
  - the plan runs newest first, in phases and milestones, with sprints and events branching out from the milestones;
  - unused milestones are hidden by default;
  - Now is centred, and past items are lighter.

  Every version since keeps v5's behaviour.
- **The style.**
  - An outside audit of the general style (docs/design/audit-2026-11-14-timeline-style.md) and a researcher's memo on current app styling (docs/design/research-2026-11-14-app-styling.md) led to v6.
  - The owner then chose the Craft iOS app as the starting style and supplied references 11 to 17 (docs/design/references/, with the owner's words in its README).
  - An outside audit on the Fable model compared v7 with those references and built the element library: docs/design/audit-2026-11-14-craft-v7.md, verbatim.
  - The owner's answers are verbatim in decisions/questions/P-005-rebrand-style.md: keep the trunk, restyled quietly; neutral now, colour later; retire the old state colours.
  - v8 applied those answers.
- **The element library.**
  - Source in docs/design/library/: the published files, plus source/ with the generators, the render check and a side-by-side image.
  - A second pass against the references fixed what still looked off: icons, glass, spacing, chips, cards, and the monospace text.
  - Icons are Phosphor (MIT), because Apple's SF Symbols can't be used on a web page.
  - Three reference colours were darkened so that text reaches 4.5:1.
  - Dark mode is assumed: the references show none.
- **Mockup v9.** docs/design/mockups/timeline-v9-craft.html is v8 plus a style layer in docs/design/mockups/build-v9/. The layer carries the library's second pass into the mockup and changes no behaviour. It was clicked through on desk, project, Now, menu and sheet with no errors.

## How the design work is done (for the next design session)
- **Scope.** The design session owns docs/design/mockups/timeline-*.html, docs/design/mockups/build-v9/, docs/design/library/ and the timeline screens under docs/design/. It touches no spec, status, decision record beyond the owner's verbatim answers, governance or pipeline file.
- **Commits.** Commit as `orchestrator` on a side branch (`orch/<task>`), merged `--no-ff` by `chief-of-staff` into the push branch. Use the committer `Claude <noreply@anthropic.com>` and the trailer `Agent-Session:`. Run surface_guard and check_all before every push.
- **Library changes.** Edit `docs/design/library/source/`, regenerate, run `check.js`, and publish. To publish, copy everything in `docs/design/library/` except `source/` into a scratch folder as `<scratch>/project/`, then make one Artifact publish to the library's URL: `root` is `<scratch>`, `file_path` is `<scratch>/project/design-system.json`, and `files` maps every other `project/...` path to itself. Then commit. The generators need Phosphor: `npm pack @phosphor-icons/core@2.1.1`.
- **Mockup changes.** Build the next version as a layer over the last, as v9 is over v8, so behaviour stays fixed unless the owner asks otherwise. Publish each version as its own page and give the owner the link.
