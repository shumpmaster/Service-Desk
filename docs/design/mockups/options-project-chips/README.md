# Project chip options (15 November 2026)

The page shown to the owner before they chose how projects are switched: v9's named chips first, then each option drawn on the real v9 screen in light and dark. Published at https://claude.ai/artifact/JjkA6cqwDLNic8ihsdmLL9 (private to the owner).

- `index.html` is the page; `img/` holds the six screenshots.
- `source/shot-opts.js` made them with Playwright from `../timeline-v9-craft.html`, swapping only the chips. Set `PHOSPHOR_ASSETS` to the `package/assets` folder of `npm pack @phosphor-icons/core@2.1.1`; it writes to `opts/` in the working folder.

The owner chose Option A, named chips, raised a little: decisions/questions/P-005-design-round-2.md.
