# Glossary

*Every code maps to its plain meaning. In chat and reports, lead with the concept; the code is
a cross-reference.*

| Code | Plain meaning |
| --- | --- |
| L-NNNN | A ledger entry in docs/LEDGER.md |
| S-NNN | A spec in specs/ |
| m<n.n> | A minor sprint (docs/sprints/) |
| T0–T3 | Project tier: throwaway, durable, product, high-stakes |
| R0–R3 | Risk class of a change, computed from the paths it touches |
| A0–A4 | Autonomy level: how far an agent may go without a human |
