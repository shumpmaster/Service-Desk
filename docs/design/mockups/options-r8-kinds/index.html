How a gate, a decision, research and a stop show

What you said: “Start drawing” (round 8, answer 7). Each kind starts with v34 as it is, then each option, live: scroll and tap inside the phones. The recommended one has a blue edge. The four A options are one family: each opens a sheet when tapped, each uses one Yours mark for what is yours, and each keeps its own icon (flag, speech, magnifier, hand). Colour stays the soft status colours and the one blue; the milestone and sprint shapes are untouched.

Where the records fall short. Whether the desk’s answer link can record a stop card’s answer, as it does a question’s, is not in the records read here; the Answer buttons are an example and send nothing. The planned decision “S-011 frozen” is the mockup’s own example. A gate’s “what it waits for” is read from the list as v34 shows it. Times on the sheets are Chicago time, converted from the records’ UTC.
