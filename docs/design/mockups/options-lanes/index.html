Lanes: four branches open at once

Newest at the top. Main is the left lane. Each branch opens a lane where it starts, the next free one to the right, and curves back into main where it merges. A lane frees up once its branch has merged, and a new branch can reuse it. At the busiest point four lines run side by side. When a branch from a far lane merges, its curve crosses the lanes between, as in a git graph. Each icon is one event, in its kind's shape.

The same graph is drawn three times, each setting main apart in a small way.
