Milestone: none (the widget's milestone, M5, is still only a proposal in its plan, so nothing here serves a milestone yet)
Asked in session: session_01QBwHGJ3UVJ6HY4SS92w7UW

WHY: The widget test ran on your phone for a day and came back "not judged": neither a pass nor a fail. Inside the Scriptable app, the first full read finished, and a later refresh matched the desk's own summary exactly. But on the home screen, none of the widget's 25 own refreshes finished, most stopped within seconds, and none of them started from the copy the app had kept. The likely reason is that the home-screen widget can't see the folder where the app kept that copy (Caches), while it can see the folder that holds the log (Documents). So the step the test was built to measure, a home-screen refresh starting from a kept copy, never happened. The test's written rules don't cleanly cover a case where that step never happens at all: they say to run the test once more after a "not judged", but they define "not judged" only for a counted refresh that did run. The Reviewer chose "not judged" as the nearest outcome and left the next step to you. Run unchanged, the test should hit the same wall. Until you rule, no more work is done on the widget. Nothing the desk does or shows changes now; option B would later change the desk's notification sender.
