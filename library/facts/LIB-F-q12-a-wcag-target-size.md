- SC 2.5.8 (Level AA): "The size of the target for pointer inputs is at least 24 by 24 CSS pixels", except: Spacing (a 24 px circle centred on each undersized target meets no other target or circle), Equivalent, Inline, User agent control, Essential.
- SC 2.5.5 (Level AAA): "at least 44 by 44 CSS pixels", with exceptions (equivalent, inline, user agent control, essential).
