# Ruling needed: Should a small arrow mark where things are now, on every timeline and plan drawing?

Milestone: none (a design follow-up after M3D; the planner gives it a milestone when it is built)
Asked in session: session_017seyaGqUxAff6E8dKWHDCR

WHY: You asked for a subtle but noticeable arrow for where we are. Today "now" is a short bar on the Timeline, bold type on the strip and tiles, and only the gold ring on Plan. Proposed: one small filled triangle in ink pointing at the present, on the Timeline's Now line, the project page's phase strip, each Home tile's drawing, Plan's next-to-reach row and an opened phase. The opened phase's ▲ "read from the bottom" arrow goes, since "↑ start at the foot" already says it. It changes frames 5, 6, 7b, H5 and 11 as drawn; no ruling. Left unruled, it stays as built.
OPTIONS:
  A. Arrow everywhere — The triangle on all five drawings; the ▲ reading arrow removed.
  B. As built — No arrow.
RECOMMENDATION: A — one shape with one meaning everywhere, small enough to stay quiet.
RISK CLASS: R0   REVERSIBILITY: reversible   BLAST RADIUS: Timeline, strip, Home tiles, Plan, opened phases
DEFAULT: B   TIMEOUT: 168
