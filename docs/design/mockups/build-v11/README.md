# Mockup v11 build layer

v11 is v10 plus the motion and line layer from `../options-motion-lines/source/`, fixed to the owner's choices of 15 November 2026: motion 5, push, and lines 4, groove. It has no switcher.

    python3 v11.py ../timeline-v10-craft.html ../timeline-v11-craft.html

- Opening a project: the desk slides 40 out to the right and fades, and the plan slides in 40 from the left, already centred on Now. Closing reverses it: the plan slides out to the left and the desk comes back in from the right. Switching projects with the chips uses the same push. The pen that drew the plan from the top down is gone. Reduced motion turns all of it off.
- Lines: the trunk, the project's line and every branch are a 6-point groove pressed into the page. The done part of a project's line fills the groove. Branches are single smooth curves with round ends.
- Now settles with a soft blue wash, not v8's yellow flash.
