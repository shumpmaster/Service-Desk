The project pills in the floating header

Your comment on v15, on a project's floating band:

"The project pills need to be part of the floating header as well."

Each phone opens on the timeline project, so scroll down inside it: today the pills scroll away and only the map and the phase row float. In each option, tap another project's pill to switch. Projects with no plan in the mockup have no floating band, so their pills stay as they are.
