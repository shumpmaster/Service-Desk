Waiting on you, as a board

The lanes run left to right on every screen: Waiting on you, Kicked back, Done. Two ways to fit them on a phone are below; pick one. Both work the same way. Each card has one button, for the one step that clears it. When you've done it, move the card to Done: it is done at once and leaves the count, with a grey note until GitHub agrees. If after about 5 minutes GitHub still doesn't show that step, the card is kicked back, with the reason. The cards are examples from 19 Oct: items that waited on you that day; the times are examples. Try both: the demo fakes GitHub's answer in seconds, not minutes.

"Kicked back" is your word; the name is yours to confirm. Your other example was "Hung up".

How each card's one step is chosen

  • Merge opens the pull request's page, where GitHub's merge button is. For a pull request that needs nothing else from you.
  • Verdict opens GitHub's new-file page for reviews/<n>/owner.md on the pull request's branch, with "Verdict: PASS" filled in. Only for a pull request whose risk class needs your verdict (R3): it is step 1 of 2, and once confirmed, a new card, step 2 of 2, the merge, appears.
  • Answer opens the answer file for a question, filled in with the question and its options; you put your letter after "Ruling:".
  • Approve opens the deploy run that is waiting for your approval.
  • Pull requests the automatic job merges itself are never cards: they are counted in the quiet line at the foot.

How each card is confirmed

Your Done counts at once. The desk then checks the one step, as often as it reads GitHub:

  • Merge: GitHub shows the pull request merged.
  • Verdict: reviews/<n>/owner.md is on the pull request's branch.
  • Answer: the answer file is on the main branch, or a pull request adding it is open.
  • Approve: the deploy run is no longer waiting.
  • If GitHub still doesn't show the step after about 5 minutes, the card leaves Done for Kicked back, with the reason and its one button, and counts again. From there you move it to Done again; if GitHub shows the step later on its own, it goes to Done by itself.
