## Lessons for the model
- **Check whether a handoff's pull request is open.** Part 57 said the owner would merge "this branch's pull request", but none had been opened. End a session with the pull request open, or say plainly that opening it is the owner's.
- **A freeze brief must ask for the spec's own change lists to be made true.** Line 11 compares the spec with the one it supersedes. A freeze that changes line 3 or the base-commit line changes that comparison too (round 5's B1).
- **The freeze gate reads plan.md's first verdict at the freezing commit.** Keep plan.md to the latest round, with earlier rounds in `_plan-rounds-*.md`, before freezing, as S-009 did. Run `check_all.sh` on the branch before pushing a freeze, not after.
- **A frozen spec needs `join-test: <its id>/J<n>` marks**, even when it says its marks stay those of the spec it extends. Add them as comments beside the old marks in the Check author's brief.
- **Fix a found defect in a check before the lock, not after.** A locked check can then change only through a new spec, and the fix here cost one Critic round and a short re-read.
- **Run local checks with the right base.** `record_checks merges` judges the first-parent line, so run it from a branch tip with its own base. Running it from the session branch against main flags every orchestrator commit, a false finding.
