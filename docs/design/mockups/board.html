Waiting on you, as a board

What waits on you, and Done. Each card has one button, for the one step that clears it, opening GitHub as prefilled as GitHub allows. When you've done it, drag the card to Done (on a phone, press and hold first), or tap "Done ✓". The desk then checks GitHub's records. If GitHub still doesn't show it done after about 5 minutes, the card moves to Kicked back with the reason, never back where you moved it from. The cards are today's real items. Try it in any frame: the demo fakes GitHub's answer in seconds, not minutes; #128 is kicked back the first time, and GitHub "confirms" it by itself a little later.

"Kicked back" is your word; the name is yours to confirm. Your other example was "Hung up".

At 700px and wider

The same board on a tablet or computer: three columns, Waiting on you, Kicked back and Done. (On a phone this frame shows the phone layout.)

How each card's one step is chosen

  • Merge on GitHub opens the pull request's page, where GitHub's merge button is. For a pull request that needs nothing else from you.
  • Add your verdict opens GitHub's new-file page for reviews/<n>/owner.md on the pull request's branch, with "Verdict: PASS" filled in. Only for a pull request whose risk class needs your verdict (R3); it then reads "Step 1 of 2: add your verdict", and once GitHub shows the verdict, "Step 2 of 2: merge".
  • Answer opens the answer file for a question, filled in with the question and its options; you put your letter after "Ruling:".
  • Approve the deploy opens the deploy run that is waiting for your approval.
  • A card you mark done shows "Checking…" in Done until GitHub's records show its step done. If after about 5 minutes they still don't, it moves to Kicked back with the reason and the same one button, and counts as waiting on you again. From there you drag it to Done or tap "Done ✓" again; if GitHub confirms it later on its own, it moves to Done by itself. It never goes back to "Waiting on you".
  • Pull requests the automatic job merges itself are never cards: they are counted in the quiet line under Done.
