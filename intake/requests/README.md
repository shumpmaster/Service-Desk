# Requests for new work (S-012)

The Chief of Staff starts a work item with `<item>.toml`: `kind = "project" | "research" | "evidence"`,
plus `question` (research) or `project` (evidence, naming a delivered project item). Item ids:
`P-nnn`, `Q-nnn`, `E-nnn`.

A refused request is final: fix the problem and file a new request with a new id.
