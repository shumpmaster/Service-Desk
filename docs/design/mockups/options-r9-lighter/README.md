# Options: a lighter background (round 9, answer 1)

Built over mockup v46 (`../timeline-v46-craft.html`). `source/build.py` writes `phone.html` (v46 with `source/lt.css` and `source/lt.js`; the option set by the phone's hash, `.light` fixing the theme, `home` staying on home); `source/page.py` writes `index.html` with the round 8 options pages' stylesheet.

| Option | Ground (light) | Fields: blue, lavender, mint |
|---|---|---|
| v46 | #f2f3f7 | .22, .21, .15 |
| A | #f7f8fb | .22, .21, .15 |
| B | #f2f3f7 | .15, .14, .10 |
| C (recommended) | #f6f7fa | .18, .17, .12 |
| D | #fafbfd | .12, .11, .08 |

Dark is unchanged in every option. In v46, in light, the ground is a pale grey (#f2f3f7) under three soft colour fields, blue at the top left, lavender at the right and a touch of mint at the foot. v42 made the fields stronger (blue 22%, lavender 21%, mint 15%) so the glass had colour to catch. Dark is not changed by any option.
